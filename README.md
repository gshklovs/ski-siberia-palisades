# Siberia Express — Palisades Tahoe

This repository no longer builds a world. It is a **308 redirect** to

    https://ski-red-dog-face.vercel.app/?travel=siberia-bowl

specs/0052 merged Siberia and the Palisades cliff band into the Red Dog Face
world as a streamed region, so there is one mountain, one world JSON and one
download. `?travel=siberia-bowl` is a second entry point into that one build,
not a second build.

`vercel.json` carries the redirect. `public/index.html` is the fallback for a
deployment that has not read the config yet — a `<meta refresh>` and a link,
nothing else.

Regenerated by `tools/export-red-dog/ship.mjs --world siberia --redirect` in
[poi-lab](https://github.com/). Do not hand-edit.
