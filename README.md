# ski-siberia-palisades

A procedural Three.js scene of Siberia Bowl and the Palisades cliff band at Palisades Tahoe.

Static site — no build step. Open `index.html` (served over HTTP, since it uses ES modules) or deploy the repo root on Vercel.

Query params: `?cam=<name>` picks a camera, `?orbit=<deg>&r=<radius>&alt=<height>` orbits the bowl, `?still` freezes the frame, `?nohud` hides the overlay.
